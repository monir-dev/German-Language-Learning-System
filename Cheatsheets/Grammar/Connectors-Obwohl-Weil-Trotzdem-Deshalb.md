# Connectors — obwohl, weil, trotzdem, deshalb

## Subordinate-clause connectors: verb শেষে

### obwohl = যদিও

**Obwohl ich müde bin, lerne ich Deutsch.**

### weil = কারণ

**Ich bleibe zu Hause, weil ich krank bin.**

Pattern:

```text
obwohl/weil + subject + ... + conjugated verb
```

## Main-clause connectors: verb দ্বিতীয় স্থানে

### trotzdem = তবুও

**Ich bin müde. Trotzdem arbeite ich.**

### deshalb = তাই / সেই কারণে

**Ich bin krank. Deshalb bleibe ich zu Hause.**

Pattern:

```text
Trotzdem/Deshalb + verb + subject + ...
```

## Important comparison

**Obwohl ich müde bin, arbeite ich.**  
যদিও আমি ক্লান্ত, আমি কাজ করছি।

**Ich bin müde. Trotzdem arbeite ich.**  
আমি ক্লান্ত। তবুও আমি কাজ করছি।

## Easy memory: logic first

### Contrast pair: obwohl / trotzdem

প্রথম ঘটনা সত্য, কিন্তু দ্বিতীয় ঘটনা তার বিপরীত বা surprising:

```text
Although X, Y.
X is true. Nevertheless, Y happens.
```

- **Obwohl ich müde bin, arbeite ich.**
- **Ich bin müde. Trotzdem arbeite ich.**

### Cause/result pair: weil / deshalb

প্রথম ঘটনা কারণ, দ্বিতীয় ঘটনা তার ফল:

```text
Because X, Y.
X is true. Therefore, Y happens.
```

- **Weil ich müde bin, schlafe ich.**
- **Ich bin müde. Deshalb schlafe ich.**

### One-line memory trick

- `obwohl/trotzdem` = **বিপরীত / তবুও**
- `weil/deshalb` = **কারণ / তাই**

## `obwohl` বনাম `trotzdem` — একই contrast, আলাদা কাজ

### `obwohl` = “যদিও X”

এটি একটি পুরো subordinate clause শুরু করে এবং verb শেষে নেয়:

**Obwohl es regnet, gehe ich spazieren.**

অথবা:

**Ich gehe spazieren, obwohl es regnet.**

### `trotzdem` = “তবুও Y”

এটি main clause-এর adverb। এর পরে verb দ্বিতীয় স্থানে থাকে:

**Es regnet. Trotzdem gehe ich spazieren.**

❌ `Trotzdem es regnet, ...` — এই pattern ব্যবহার করবে না।

### Same meaning, two structures

```text
Obwohl ich krank bin, gehe ich zur Arbeit.
Ich bin krank. Trotzdem gehe ich zur Arbeit.
```

মনে রাখবে:

```text
obwohl = যদিও + কারণ/অবস্থা
trotzdem = তবুও + main action
```


## Common mistakes

- `kein Zeit` → **keine Zeit** (`die Zeit`)
- `trotzdem` sentence-এর শুরুতে হলে **Trotzdem**
- `mache ich arbeiten` → **arbeite ich**
