# Cheatsheets

এই folder-এ lecture-এর পাশাপাশি তৈরি হওয়া topic-wise quick revision notes থাকবে। এগুলো chat ছাড়াই Obsidian-এ দ্রুত revision করার জন্য লেখা হবে।

## Automatic update rule

প্রতিটি lecture শেষে agent:

1. নতুন topic শনাক্ত করবে।
2. Topic-এর cheat sheet না থাকলে তৈরি করবে।
3. আগে থাকলে নতুন rule, example, mistake ও evidence দিয়ে update করবে।
4. Lecture, [[Cheatsheet-Index]], Dashboard এবং relevant tracker-এ link যোগ করবে।
5. Cheat sheet তৈরি বা update করার জন্য learner-এর reminder চাইবে না।

Cheatsheet হলো quick revision source; full explanation ও exact learner evidence থাকবে lecture file-এ।
