## Current context: Data Warehouse synchronization

### Source headings

- `Synchronisierung ins Data Warehouse`
- `Status der Synchronisierung`

### Useful phrases

- `die Synchronisierung ins Data Warehouse` — synchronization to the data warehouse
- `der Status der Synchronisierung` — synchronization status
- `die Anzahl der Verträge` — number of contracts
- `Verträge, die noch synchronisiert werden müssen` — contracts that still need to be synchronized

### Correct sentence

`Anzahl der Verträge, die noch synchronisiert werden müssen.`

`müssen` is plural because `die` refers to `die Verträge`.
