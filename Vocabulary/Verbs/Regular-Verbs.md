# Regular Verbs

Regular verbs follow predictable endings. Start with the high-utility verbs below.

| Verb | Meaning | Topic | Präsens status | Präteritum status |
|---|---|---|---|---|
| machen | করা | daily actions | Practiced | Practiced |
| lernen | শেখা | study | Practiced | Practiced |
| arbeiten | কাজ করা | work | Practiced | Practiced |
| wohnen | বসবাস করা | home | Not started | Not started |
| sagen | বলা | communication | Not started | Not started |
| fragen | জিজ্ঞেস করা | communication | Not started | Not started |
| antworten | উত্তর দেওয়া | communication | Not started | Not started |
| brauchen | প্রয়োজন হওয়া | needs | Not started | Not started |
| kaufen | কেনা | shopping | Not started | Not started |
| suchen | খোঁজা | daily actions | Not started | Not started |
| warten | অপেক্ষা করা | time/social | Not started | Not started |
| versuchen | চেষ্টা করা | learning | Not started | Not started |
