# German Learning Syllabus

## Mission

Build reliable German communication from the current B1.1 class level toward C1, with confident everyday speaking as the first milestone.

## Active phase

**Phase 3 — B1.1 consolidation**

The active phase is controlled by [[Current-Progress]]. Other phases may be marked `Learning` for preparation, but the agent must teach from the active phase unless revision evidence requires a prerequisite review.

## Status key

`Not started` · `Learning` · `Practiced` · `Needs revision` · `Stable`

No topic is considered completed merely because it was explained once.

## Phase 0 — Baseline and system setup

- Establish grammar, vocabulary, conjugation, speaking, writing, listening, and pronunciation baselines.
- Identify recurring errors with dated evidence.
- Set a sustainable 10–15 minute practice habit.

## Phase 1 — A1 foundation repair

- Pronouns, articles, gender, plural, negation, questions.
- `sein`, `haben`, regular verbs, common irregular verbs.
- Präsens word order and basic prepositions.
- Everyday survival vocabulary and sentence frames.

## Phase 2 — A2 core

- Akkusativ and Dativ articles/pronouns.
- Modal verbs, separable verbs, reflexive verbs.
- Perfekt and common Präteritum forms.
- `weil`, `dass`, `wenn`, comparatives, appointments, travel, health, work, home.

## Phase 3 — B1.1 consolidation

- Reliable narration in Präsens and Perfekt.
- Essential Präteritum: `sein`, `haben`, modal verbs, common high-frequency verbs.
- Verb-preposition combinations.
- Relative clauses, subordinate-clause word order, opinions and reasons.
- Active vocabulary expansion and short spontaneous speaking.

## Phase 4 — B1.2

- Longer conversations, explanations, complaints, plans, experiences.
- Konjunktiv II basics, passive basics, connectors and discourse markers.
- Structured writing and speaking feedback.

## Phase 5 — B2

- Nuanced opinions, argumentation, formal and informal registers.
- Complex connectors, passive variations, nominal style, collocations.
- Listening and speaking stamina.

## Phase 6 — C1

- Precise vocabulary, idiomatic phrases, abstract discussion.
- Register control, complex writing, presentations, debate, and exam tasks.
- C1 assessment only after evidence across all four skills.

## Progress rule

Each phase is advanced by evidence, not by calendar time. The agent must use [[Dashboard]], [[Current-Progress]], [[Error-Log]], and recent lecture notes to select the next target.
